AI-Powered Tomato Leaf Disease Detection System

This project showcases an AI system that can detect the condition of tomato leaves based on images and pictures. The AI can identify whether a tomato leaf is healthy or affected by a specific type of disease.

The system uses Resnet as its primary object detection model. The Ai can accurately recognize different leaf condition base on the images provided on a tomato leaf

Once a tomato leaf is detected, the AI labels it as either Healthy or identifies the specific disease affecting it. This enables people  to quickly recognize the condition of the plant.

The goal of this project is to help farmers identify diseases affecting their tomato plants more efficiently. By detecting diseases early, farmers can apply the appropriate treatment based on the leaf condition, and overall improve plants health.

As this project is still in its early stages of development, some errors are expected to be found.

Dataset Used

Dataset: https://www.kaggle.com/datasets/cyrilrajc/tomato-leaf-disease-image-classification

This dataset contains thousands of images of tomato leaves with various diseases, as well as healthy leaves. The AI is trained to recognize patterns and visual characteristics from these images. This allows it to identify whether a leaf is healthy or affected by a specific disease.
